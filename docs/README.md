## 🤝 Contributing to Documentation

Documentation improvements are always welcome! When contributing:

1. **Keep it practical** - Include working examples and real use cases
2. **Stay current** - Update docs when making code changes
3. **Be comprehensive** - Cover edge cases and error scenarios
4. **Follow patterns** - Maintain consistency with existing docs

### Documentation Standards
- Use clear, descriptive headings
- Include code examples with proper syntax highlighting
- Add practical usage examples
- Keep table of contents up-to-date
- Cross-reference related sections
